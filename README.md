# Blossom for Claude

Deploy, manage, and debug Apps in your cloud or ours.

## Install on your Mac

In **Customize → Plugins**, choose **Add → Add marketplace → Add from a
repository** and enter `blossom-cloud/claude-plugins`. Select
**Blossom** and connect your Blossom Account.
Claude needs read access to this private repository.

## Install in Claude Code

    /plugin marketplace add blossom-cloud/claude-plugins
    /plugin install blossom@blossom

Open `/mcp`, select Blossom, and sign in.
